Automated Ubuntu server hardening using Ansible based on CIS benchmarks.

**Features:**
- Ansible playbooks for CIS Level 1 & Level 2 compliance
- Automated security scanning and reporting
- Pre/post hardening comparison
- CI/CD validation with GitHub Actions
